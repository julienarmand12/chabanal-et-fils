CHABANAL ET FILS — V2.2 PWA

Cette version reprend V2.1 et ajoute uniquement les éléments PWA nécessaires à l’installation sur téléphone, tablette et ordinateur. La synchronisation Supabase et les fonctions V2.1 sont conservées.

FICHIERS À HÉBERGER ENSEMBLE
- application_metier_v2_2.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

IMPORTANT
Le site doit être servi en HTTPS pour l’installation PWA sur téléphone/ordinateur (localhost est accepté pour les tests locaux).

ANDROID / CHROME
Ouvrir le site, puis menu ⋮ > Installer l’application / Ajouter à l’écran d’accueil selon le navigateur.

WINDOWS / CHROME OU EDGE
Ouvrir le site. Le navigateur peut afficher l’icône d’installation dans la barre d’adresse ou proposer « Installer Chabanal et fils ». Une icône est alors créée dans les applications et permet de lancer l’application dans une fenêtre dédiée.

Le logo utilisé pour l’icône est dérivé du logo affiché en haut à gauche de l’application V2.1.
