Copie de sécurité des clients dans IndexedDB

Téléphone 1 uniquement — copie isolée, sans bascule de l’application

Cette page prépare une copie des fiches cloud dans IndexedDB. Elle ne modifie pas la liste clients actuelle dans localStorage, n’efface aucune donnée, ne modifie pas Supabase et n’active pas encore IndexedDB dans l’application.

Ne pas utiliser sur le téléphone 2. Ne pas vider le cache ni les données du navigateur.

Rapport

En attente du contrôle.

Copie contrôlée

La copie ne sera autorisée que si la liste locale actuelle est valide, si le cloud contient les 757 fiches attendues, si la file clients est vide et si l’emplacement IndexedDB destiné à cette copie est encore vide. Si un snapshot existe déjà, la page s’arrête sans le remplacer.
