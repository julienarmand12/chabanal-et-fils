# Chabanal et fils — V2.2 PWA

Cette version est basée sur la V2.1 validée. Elle ajoute uniquement les éléments PWA nécessaires à l'installation sur téléphone : manifeste, icônes utilisant le logo du site et service worker.

## Installation
Le dossier doit être hébergé sur une adresse HTTPS. Ouvrir ensuite `index.html` dans Chrome Android et choisir « Ajouter à l'écran d'accueil » / « Installer l'application ».

## Important
La V2.1 originale reste inchangée comme sauvegarde. Ne pas supprimer la V2.1.
